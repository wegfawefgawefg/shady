Shady is a WGSL workshop.

It gives a shader the whole screen, four channels, feedback buffers, live inputs, and an editor that gets out of the way. The native C++ runner and this WebGPU page use the same small shader contract.

The project grew out of an assembly shader toy. That experiment built a surprisingly complete rendering shell, but its fake language became the least useful part when the actual goal was making and porting visual effects. Shady keeps the shell and makes the authored source ordinary WGSL.

Why not imitate Shadertoy exactly?

Shadertoy uses GLSL and the web platform is converging on WGSL. Pretending those languages are identical would require another compiler. Shady copies the useful shape instead: one function per pixel, time, mouse, textures, feedback, sharing, capture, and fast iteration.

Start with fn shade(pixel: ShadyPixel) -> vec4<f32>, choose a template, and make something strange.
